# Security and Regulatory Compliance

## Data sovereignty and encryption
All data at rest is encrypted using AES-256 with tenant-isolated customer-managed keys (KMS). Data in transit is protected via TLS 1.3 with forward secrecy.

## SOC 2 Type II and ISO 27001
Our infrastructure undergoes annual SOC 2 Type II audits performed by independent AICPA-accredited assessors. Reports covering security, availability, and confidentiality are available to customers under mutual NDA.

## Data retention and deletion
Upon contract termination, all customer vector embeddings and database rows are purged from active storage within 14 calendar days, with offsite backup purges completed within 30 days.
